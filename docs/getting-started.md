# Getting Started

This page provides basic information for Archery Things.

## Installation

Archery Things can be downloaded on CurseForge and Modrinth.

| Platform   |                                           Link                                           |
|------------|:----------------------------------------------------------------------------------------:|
| CurseForge | [Download from CurseForge](https://www.curseforge.com/minecraft/mc-mods/archery-things)  |
| Modrinth   |            [Download from Modrinth](https://modrinth.com/mod/archery-things)             |

## Supported Versions

| Mod Loader       | Minecraft Version |    Maintaining     |
|------------------|:-----------------:|:------------------:|
| NeoForge, Fabric |      1.21.11      | :white_check_mark: |
| NeoForge, Fabric |      1.21.10      | :white_check_mark: |
